# Benchmark visual enterprise (patrones, no copias)

Fecha: 2026-08-21. Referencias usadas **solo para extraer calidad**. No se copian layouts, copy, ilustraciones ni assets.

| Referencia (tipo) | Elemento valioso | Riesgo de copiar | Interpretación original para Justech |
| --- | --- | --- | --- |
| Integradoras de infraestructura / data center | Hero como **sistema en operación**, no un slogan sobre stock | Copiar el “edificio de cristal + partículas” | Campus + sucursales + rack + nube como **una sola malla** con Justech como hilo |
| Proveedores de red (enterprise, no retail) | Topologías que se pueden leer; zoom de campus a puerto | Dashboard de un fabricante concreto | Escena de sede/sucursal/AP/tráfico **sin marca de switch** |
| Ciberseguridad enterprise | Prueba y capas, no miedo | Hoodies, matrix, candados gigantes, SOC 24/7 falso | Capas ejecutiva: perímetro → identidad → endpoint → dato → respaldo; un evento se **aísla** y la operación sigue |
| MSP / mesa de ayuda | Flujo de caso con dueño | Inventar SLAs, NOC propio, cifras | Portal **simulado** (prioridad, N1–N3, cierre) con horario publicado |
| Cloud / hiperescalares | Migración como oleadas, no “lift and shift” mágico | Copiar ilustraciones de nubes sonrientes | Local → evaluación → sincronización → validación → híbrido |
| Consultoras de transformación | Tipografía y espacio; menos tarjetas | Parecer bufete o banco de 1998 | Precisión “private banking tech”: navy, señal, mono para datos, **sin serif de periódico** |
| Licenciamiento B2B | Usuarios y puestos, no SKU | Logos de Microsoft/Google sin permiso | Departamentos que se **asignan** a un tenant abstracto |
| Cableado / obra técnica | Before/after de planta | Foto de obra ajena o CCTV no confirmado | Plano → ruta → rack vestido → etiqueta → certificación (simulación) |
| Firmas digitales premium | Ritmo cinematográfico; una idea por secuencia | Home-sitemap | Doce secuencias, **sin** listar el inventario completo |
| Banca / instituciones (tono, no look) | Discreción, control, detalle | Mármol, dorado, escudos | Lujo = precisión de ejecución, no ornamentación |

## Patrones retenidos

1. Hero de **resultado operativo**.
2. Prueba pequeña y verdadera cerca del CTA.
3. Visualización funcional (se entiende qué hace la empresa).
4. Páginas insignia con identidad propia, no un molde.
5. Conversión por **necesidad**, no un solo “Contacto”.

## Patrones rechazados

Plantilla de tarjetas, blobs SaaS, partículas gratuitas, Three.js de demostración, logo farms, contadores, 24/7, partnership inventado, cursor que sustituye al sistema.
