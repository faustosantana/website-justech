# Benchmark visual (patrones, no copias)

Referencias revisadas en agosto 2026 **solo para extraer patrones de calidad**. No se copian layouts, textos, ilustraciones ni marcas.

## Tipos de sitio

| Tipo | Qué se observó como calidad | Qué se descartó |
| --- | --- | --- |
| Integradoras de infraestructura | Hero de capacidad de ejecución; proceso visible; mezcla de obra física y TI | Galería de productos tipo tienda |
| Proveedores de data center / redes | Diagramas de topología; profundidad en navy; CTAs de levantamiento | Neón, partículas gratuitas, 3D decorativo |
| Ciberseguridad enterprise | Narrativa de riesgo → control; UI simulada de operación | Miedo excesivo, stock de candados |
| Consultoras de transformación | Editorial, tipografía con carácter, casos con resultado | Tarjetas idénticas, “transformamos el mañana” |
| Cloud / hiperescalares | Capas (infra, plataforma, operación); navegación profunda | SaaS gradient blobs, ilustraciones cute |
| B2B industrial | Confianza verificable; formularios por intención; menos marketing vacío | Contadores inventados, logo farms |

## Patrones retenidos para Justech

1. **Resultado operativo en el hero**, no un slogan genérico.
2. **Prueba pequeña y verdadera** (fundación, ciudad, portal, teléfono) en lugar de cifras infladas.
3. **Arquitectura comercial completa** en el menú (soluciones, servicios, productos, industrias).
4. **Visualización funcional**: la red que conecta personas, sitios y operación.
5. **Páginas profundas** (problema, señales, alcance, proceso, FAQ), no fichas de 80 palabras.
6. **Conversiones por intención**, no un único formulario “Contacto”.

## Dirección resultante

Concepto: **“La red que sostiene el negocio.”** Paleta navy/teal/papel evolucionada con signal `#5eead4` y titulares en IBM Plex Serif. Motion: canvas 2D + revelado por scroll, con fallback estático y `prefers-reduced-motion`.
