# Iteración v3 — experiencia cinematográfica

No es el sitio final. Es el primer corte de **mundos visuales** sobre seis páginas insignia.

## Concepto

La capa que mantiene el negocio en movimiento. Canvas 2D propio (no Three.js). Tipografía Red Hat Display + Plex Sans + Plex Mono.

## Seis insignia

Home, `/redes/`, `/seguridad/`, `/licenciamiento/`, `/soporte/` + MSP, `/infraestructura-fisica/`.

Más: `/productos/laptops/`, `/industrias/multisucursal/`, `/resolver/`, `/recursos/guia-levantamiento/`.

## Autocrítica

Sigue sin fotografía de obra real ni casos. Las escenas 2D son lenguaje propio, no un demo de partículas, pero un WebGL de estudio (con presupuesto) podría ir más lejos **después** si el LCP se mantiene. Las fichas `[slug]` antiguas aún usan el molde CapabilityPage: **no se propagó** a 100 páginas a propósito.
