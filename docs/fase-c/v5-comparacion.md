| | V4 | V5 |
| --- | --- | --- |
| Home | Canvas de nodos + 6 capas + listas | Un still cinematográfico + 9 capítulos sobre la misma escena (foco, no menú) |
| Redes | Constelación + 5 tabs + botones de caída | Foto de planta anotada. 4 vistas. Sin cajas SVG |
| Laptops | Laptop esquemática + 8 perfiles + wizard | Render de producto + 5 perfiles, uno visible |
| Licencias | Cajas y configurador | Still de consola de tenant + un paso |
| Soporte | Dashboard de consola densa | Still del caso + avance lineal |
| Header | 8 grupos, inventario | Capacidades por intención, Productos, Empresa, Soporte |
| Motion | Muchos canvas simultáneos | Un foco; foto + HTML |
| Copy | Titulares con “no” | Lenguaje positivo |

Componentes V4 **fuera de las maestras**: LayerSystem, NeedPicker, ProcessTrack, LaptopRig, NetworkExplorer, LicenseOrg, SupportConsole, TechScene en home.

No se propagó el estándar al long-tail `[slug]`.
