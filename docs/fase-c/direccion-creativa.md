# Dirección creativa v2 — Justech

Referencias usadas **solo como patrones de calidad** (no se copian layouts, textos ni assets): integradoras de infraestructura, MSP, ciberseguridad y cloud enterprise. Patrones retenidos: hero de resultado, prueba operativa (no logo farm), divulgación progresiva, visualización funcional, CTAs de alcance.

## Concepto

**“La red que sostiene el negocio.”** Justech conecta personas, sitios, datos y operación. El visitante debe percibir capacidad de ejecución de extremo a extremo (evaluar → diseñar → suministrar → implementar → operar), no un catálogo de seis fichas.
