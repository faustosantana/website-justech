# Comparación antes / después (v3)

No es un rediseño cosmética de colores. Cambia el **modelo mental**: de catálogo a sistema operativo.

| | www.justech.do (producción) | Staging v3 |
| --- | --- | --- |
| Primera impresión | Sitio WordPress de integrador local | Escena de una organización en operación |
| Hero | Texto + fotografía genérica o slider | Historia 5.2 s: infra → red → software → seguridad → monitoreo |
| Oferta | Lista de servicios | Seis capas conectadas + CTA de diagnóstico |
| Páginas de capacidad | Fichas parecidas | Mundos: redes, seguridad, licencias, soporte, MSP, cableado |
| Tipografía | Stack de plantilla | Red Hat Display + IBM Plex Sans + Plex Mono |
| Motion | Poco o plugins | Gramática por capacidad; reduced-motion = estático |
| Conversión | Formulario único / WhatsApp no confirmado | «¿Qué necesita resolver?» + intents |
| Confianza | Logos o cifras no gobernadas | Solo señales verificadas (2018, portal, horario, teléfono) |
| Indexación staging | n/a | `noindex` + robots Disallow |

## Lo que aún no alcanza el listón de junta

- Fotografía de obra y de equipo **real y autorizada**.
- Casos, clientes, certificaciones, partnerships.
- El long-tail `[slug]` sigue el molde CapabilityPage (deliberado).
- LCP móvil de laboratorio 3.6 s (render delay del hero; desktop 0.7 s / 100).
- GitHub Pages no publica (403 histórico / 404 actual).
